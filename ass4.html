Part 3: Upload Your Project to GitHub

Step 1: Create a Project Folder

Create a folder named:

assignment-4

Save this code inside a file named:

index.html

Step 2: Open the Terminal

Open your project folder in your code editor and open its terminal.

Step 3: Initialize Git

git init

This starts Git version control in your folder.

Step 4: Add and Commit Your File

git add . git commit -m "Create Assignment 4 Counter App"

A commit saves a version of your project.

If Git asks you to configure your username or email, set your Git name and email before committing.

Step 5: Create a GitHub Repository

Open GitHub and create a new repository named:

assignment-4

For this beginner exercise, create an empty repository without adding a README or license.

Step 6: Connect Your Project

Copy your repository URL from GitHub and run:

git branch -M main git remote add origin https://github.com/USERNAME/assignment-4.git

Replace USERNAME with your actual GitHub username.

Step 7: Push Your Code

git push -u origin main

Your committed code will now be uploaded to GitHub.

Part 4: Learn Git Clone

What is git clone?

Git clone downloads a copy of an existing GitHub repository to your computer, including its available project history.

Step 1: Copy the Repository URL

Open your GitHub repository, click the Code button, and copy its HTTPS URL.

Step 2: Open a Different Folder

Open the terminal in the location where you want to download the project. Do not open it inside your existing assignment-4 folder.

Step 3: Clone the Repository

Run this command using your actual repository URL:

git clone https://github.com/USERNAME/assignment-4.git

Git will create a new folder named assignment-4 containing the project.

Step 4: Open the Cloned Project

cd assignment-4

Check the files and Git status:

git status

You can now open index.html in your editor and run the project in your browser.

Remember:

git clone copies an existing repository to your computer.

git push sends your local commits to the remote repository.

git pull downloads and integrates changes from the remote repository.

Part 5: Practice Version Control

After cloning the project, practise making a change.

1. Change the Project

For example, change the page heading or add a short description to the counter.

2. Check Your Changes

git status

3. Add the Changes

git add .

4. Create a New Version

git commit -m "Update counter app"

5. Upload Your Changes

git push

If you cloned a repository belonging to someone else and do not have write permission, create your own fork or repository before pushing.
