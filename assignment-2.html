Part 2 — What is Git?

Git is a Version Control System. It helps developers track and manage changes made to their projects.

Think of Git as a history book for your code. Every important version of your project can be saved as a commit.

Without Git

You may have many copies such as project-final, project-final2, project-final-new, etc.

With Git

Git keeps the history of your project in an organized way.

Part 3 — What is GitHub?

GitHub is an online platform where developers can store, manage and share Git repositories.


Git

Manages project versions on your computer.

GitHub

Stores your Git project online.

Part 4 — Connect Your Project with Git

Step 1 — Create Project Folder

Create a folder named:

Assignment-3

Inside the folder save this file as:

index.html

Step 2 — Open Terminal

Open your project folder in VS Code or Command Prompt and open the terminal.

Step 3 — Initialize Git

Run this command:

git init

This starts Git version control for your project.

Step 4 — Check Git Status

git status

This command shows which files have been created or changed.

Step 5 — Add Your Files

git add .

This prepares your changes for the next commit.

Step 6 — Create Your First Commit

git commit -m "Initial Assignment 3"

A commit saves a version of your project.

Part 5 — Create GitHub Repository

Step 1 — Open GitHub

Go to GitHub and create a new repository.

Repository name:

assignment-3

Step 2 — Connect GitHub Repository

Copy your GitHub repository URL and run:

git remote add origin https://github.com/USERNAME/assignment-3.git

Replace USERNAME with your GitHub username.

Step 3 — Set Main Branch

git branch -M main

Step 4 — Push Your Project

git push -u origin main

Push sends your local project commits to GitHub.

Part 6 — Learn Version Control

1. Check the Change

3. Save a New Version

4. Upload the New Version

Part 7 — View Version History

To see all your previous commits, use:

git log --oneline

You may see something like:

a82f123 Updated developer title
b73d921 Initial Assignment 3

Each commit represents a saved version of your project.

Part 8 — Important Git Commands

git init

Starts Git in your project.

git status

Shows project changes.

git add .

Adds changes for the next commit.

git commit -m "message"

Saves a new version of your project.

git push

Uploads your commits to GitHub.

git pull

Gets the latest changes from GitHub.

git clone URL

Downloads a GitHub repository to your computer.

Part 9 — Git Workflow

Whenever you make changes to your project, follow this process:

EDIT CODE → git status → git add . → git commit → git push → GITHUB

Remember: Edit → Add → Commit → Push
